### Final Reflection

1. **How does Git help in maintaining research traceability?**
   Git tracks all changes made to files over time, allowing researchers to see what was changed, when, and by whom. This ensures a clear history of the research process and supports transparency.

2. **Why is GitHub useful for academic collaboration?**
   GitHub enables multiple researchers to work on the same project, share code and data, review changes, and collaborate efficiently in a centralized platform.

3. **Why should researchers create branches instead of working directly on main?**
   Branches allow safe experimentation without affecting the main codebase, reducing the risk of errors and enabling controlled integration of changes.

4. **What is the role of Pull Requests in collaborative work?**
   Pull Requests allow team members to review, discuss, and approve changes before merging, ensuring code quality and correctness.

5. **Why are reproducibility files important in research repositories?**
   They provide clear instructions, dependencies, and data details so others can replicate the results, which is essential for validation and credibility.

6. **What is the purpose of creating a version tag such as v1.0.0?**
   Version tags mark stable releases of the project, helping track progress and allowing users to reference specific versions of the work.

7. **Why should a repository include a citation file?**
   A citation file provides proper credit to the authors and allows others to reference the work correctly in academic publications.

8. **How does this semester’s Git/GitHub workflow support better PhD research practice?**
   It promotes structured development, proper documentation, version control, collaboration, and reproducibility, which are essential for high-quality and reliable research.
